# DIINI AI Real Estate

Multi-tenant AI real estate sales, reception, and lead automation SaaS.

## Local development

1. Install dependencies with `pnpm install`.
2. Copy `.env.example` to `.env.local` and add the Supabase project values.
3. Start the development server with `pnpm dev`.
4. Open `http://localhost:3000`.

## Verification

Run the project checks before committing changes:

```bash
pnpm typecheck
pnpm lint
pnpm build
```
